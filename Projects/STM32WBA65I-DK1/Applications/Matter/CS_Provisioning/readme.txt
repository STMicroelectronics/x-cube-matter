The CS_Provisioning example is used to generate the Device Attestation
Certificate (DAC) and key pair.
It is part of the Factory Data provisioning procedure described in more detail
in the wiki:
https://wiki.st.com/stm32mcu/wiki/Connectivity:Matter_device_factory_data_provisioning

@par Keywords

Matter,DAC

@par Directory contents 

 
  Uses the Matter SDK.
  
 
@par Hardware and Software environment

  - This example has been tested with an STMicroelectronics STM32WBA65I-DK1 board.
    
@par How to use it?
Refer to the wiki.


Minimum requirements for the demo:
- 1 STM32WBA65I-DK1 board.


**** START DEMO ****
Follow the instructions defined in the wiki.


**** LED SUMMARY ****
- When the DAC private key is successfully stored in flash, the green LED turns on.
- When DAC private key storage fails, the green LED blinks.
