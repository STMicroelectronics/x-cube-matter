Release Notes for X-CUBE-MATTER

Copyright © 2025 STMicroelectronics

Purpose

  • This expansion package provides Matter over Thread, WiFi or ethernet connectivity.

  • Applications with and without OTA support are provided for STM32WBA-DK1 and X-NUCLEO-67W61M1 + NUCLEO-U575ZI boards

  • Note that OEMiRoT used for secure boot and OTA is based on example provided into official CubeFW STM32WBA. OEMiRoT is applicable to STM32WBA only.

  • Projects Release Note is here: \Projects

Here is the list of references to the user documents:

  • Matter STMicroelectronics MCU Wiki - ST Wiki dedicated to MCU, Matter page
  • DB5144 - Data Brief of the Matter software expansion for STM32Cube

Update history

Main changes

  • Upgrade to Matter SDK 1.5.0.1 on all platforms
  • Add OTA support on X-NUCLEO-67W61M1 + NUCLEO-U575ZI
  • Add Matter Provisioning support for X-NUCLEO-67W61M1 + NUCLEO-U575ZI

WBA6:

  • Update to CubeFW WBA 1.9.0

U5:

  • Update to ST67W61 1.2.0

Security

  • Upgrade to MbedTLS 3.6.5

Known limitations

With WBA6, following limitations identified:

  • Only Non-Secure Application can be updated through OTA.
  • No Low power support for OEMiROT
  • TC-CGEN-2.2 and TC-I-2.2 are failed on Generic-Switch-App.
  • TC-S-2.6 and TC-CNET-4.12 have not been executed.

With U5+ST67, following limitations identified

  • Only Non-Secure Application can be updated through OTA.
  • TC-S-2.6 and TC-SC-4.9 have not been executed.
  • TC-CNET-4.11 is failed.

Development toolchains and compilers

  • STM32CubeIDE v1.18.0 for STM32WBA, NUCLEO-H753ZI and NUCLEO-U575ZI + X-NUCLEO-67W61M1
  • STM32CubeProgrammer v2.20.0 for STM32WBA, NUCLEO-H753ZI and NUCLEO-U575ZI + X-NUCLEO-67W61M1

Supported devices and boards

  • STM32WBA65I-DK1
  • NUCLEO-H753ZI
  • X-NUCLEO-67W61M1 + NUCLEO-U575ZI

Backward compatibility

  • Yes

Dependencies

This software release is compatible with

  • STM32CubeFW_WBA V1.9.0
  • STM32CubeFW_H7 V1.12.1
  • STM32CubeFW U5 V1.8.0
  • X-NUCLEO-67W61M1 V1.2.0
  • CSA Matter SDK V1.5.0.1 (https://github.com/project-chip/connectedhomeip/tree/v1.5.0.1)
  • Thread 1.4 support (OT commit SHA-1: cbb04be4a64910a8ad160ae1aae2e34fc31031b9 - June 9,2025)
  • OEMiRoT from STM32CubeFW_WBA v1.9.0 for STM32WBA
  • TFM SHA1: 63bcfc10cc2

WBA6:

  • Update to CubeFW 1.7.0

  • Python installation is required to execute RoT provisioning.

  • ST and Arris Technology pre-integrated solution to provision Matter certificates to STM32WBA65I-DK1 devices.

  • TC-ICDM-3.2, TC-ICDM-5.2 are failed with Generic-Switch app.
  • TC-ICDB-1.2, TC-ICDB-3.1, TC-ICDB-3.2 are failed with Generic-Switch app
